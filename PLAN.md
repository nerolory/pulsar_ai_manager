# LLM Chat — Plan

## 1. Vision / Attachments (отложено)
- `ChatMessage.content` → `str | list` (text + image parts)
- `VseLLMProvider` + `OpenRouterProvider` — передавать content как список если это list
- Frontend: Ctrl+V paste перехват, превью изображения, кнопка 📎 → `<input type="file">`
- При отправке — конвертация в base64, передача как OpenAI image_url
- `ChatMessages` — рендер изображений в пузыре

---

## 2. Быстрые пресеты (скрипт)
- Пресеты не показываются постоянно — только как выпадающий список при вводе в поле скрипта
- Хранить последние 10 использованных пресетов
- Персистировать в localStorage (это не секретные данные, объём маленький)

## 3. Скролл чата при перезагрузке
- При загрузке страницы — скроллить к началу последнего ответа от LLM, не к самому низу

## 4. Персистенция чата на бэкенде
- Убрать хранение сообщений из localStorage
- Хранилище: SQLite (через aiosqlite) — легковесное, файловое, без сервера, портативное
  - Альтернатива: JSON-файлы (проще, но медленнее при большом объёме)
  - Решение: SQLite — оптимально для десктоп/контейнер, поддерживает индексы
- Персистировать в Docker volume `backend_data` (уже создан)

## 5. Виртуализация / пагинация чата
- При загрузке — отображать последние 10 сообщений
- При скролле вверх — подгружать следующие 10 (infinite scroll вверх)
- Подгрузка должна быть незаметной (сохранять позицию скролла)
- API: `GET /api/v1/chat/{chat_id}/messages?before={id}&limit=10`
