# PulsarAI Chat — Roadmap

## Обзор проекта

PulsarAI Chat — это LLM чат-бот с поддержкой множества провайдеров (VseLLM, OpenRouter, Mock). Проект разработан для портфолио и распространяется бесплатно. Коммерческое использование запрещено.

**Технологический стек:**
- Backend: Python 3.13, FastAPI 0.115, Pydantic v2.13, PyInstaller
- Frontend: Vue 3.5, Vite 6, TypeScript 5.7, Pinia
- Desktop: Electron 35, electron-builder 26
- Инфраструктура: Docker, Docker Compose
