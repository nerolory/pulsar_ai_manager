## Автоматическая маршрутизация через модели безопасности OpenRouter

**Статус:** Отложено
**Приоритет:** Высокий

**Проблема:**
OpenRouter автоматически маршрутизирует запросы через модель безопасности NVIDIA Nemotron Content Safety, которая возвращает сервисные сообщения вроде "User Safety: safe" вместо реального ответа LLM. Это поведение нельзя отключить через параметры API.

**Корневая причина:**
OpenRouter имеет встроенную модерацию контента, которая перехватывает запросы и маршрутизирует их через модели безопасности перед тем, как запрос достигнет целевой модели. Ответ модели безопасности возвращается как часть потока.

**Результаты исследования:**
- Модель безопасности: nvidia/nemotron-3.5-content-safety-20260604:free
- Ответ приходит как обычные chunks потока с полем model, установленным в название модели безопасности
- Не найден параметр API для отключения этого поведения (проверены provider.ignore, provider.allowFallbacks и др.)
- Документация не упоминает, как отказаться от автоматической маршрутизации безопасности

**Возможные решения:**
1. Связаться с поддержкой OpenRouter - запросить параметр API или настройку аккаунта для отключения автоматической маршрутизации через модели безопасности
2. Проверить настройки аккаунта - уточнить, есть ли настройка приватности/безопасности в аккаунте OpenRouter для отключения этого
3. Использовать прямые API провайдеров - обойти OpenRouter и использовать API провайдеров напрямую (OpenAI, Anthropic и др.)
4. Фильтрация на клиенте - фильтровать chunks от моделей безопасности, проверяя поле model (не рекомендуется как временное решение)

**Текущее состояние:**
- Проблема задокументирована, ожидается решение пользователя о подходе
- Изменения кода не внесены
