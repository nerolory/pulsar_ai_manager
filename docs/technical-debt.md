### Рефакторинг системы роутеров под БД

**Статус:** Отложено
**Приоритет:** Высокий

**Цель:**
- Унифицировать вызов моделей под один объект с разными моделями
- Создать единую входную точку для всех LLM

**Подход:**
1. Использовать декораторы для вызова роутеров
2. Декоратор будет подставлять дополнительный класс, который обрабатывает все необходимые действия для роутера
3. Не нужно будет через единую точку вызывать разные классы - декоратор сам будет этим заниматься

**Преимущества:**
- Единая точка входа для всех LLM
- Упрощение архитектуры
- Легче добавлять новые провайдеры

## Отложенные провайдеры

Провайдеры, которые требуют дополнительной интеграции из-за сложной авторизации.

## GigaChat (Сбер)

**Статус:** Отложен
**Причина:** Сложная OAuth авторизация

**Требуемая авторизация:**
1. Получить Authorization key в личном кабинете
2. POST `https://ngw.devices.sberbank.ru:9443/api/v2/oauth` с Authorization key
3. Получить access token (время жизни ~30 минут)
4. Использовать access token в заголовке Authorization: Bearer {token}

**Альтернативный вариант:**
- Использовать OpenAI-совместимый прокси (например gpt2giga от ai-forever)
- GitHub: https://github.com/ai-forever/gpt2giga
- Позволяет использовать GigaChat через стандартный OpenAI API

**Документация:**
- REST API: https://developers.sber.ru/docs/ru/gigachat/api/reference/rest/gigachat-api
- Получение токена: https://developers.sber.ru/docs/ru/gigachat/api/reference/rest/post-token

**Бесплатный тариф:**
- 1,000,000 токенов бесплатно
- Период: 12 месяцев
- Модели: GigaChat, GigaChat-2, GigaChat-Pro, GigaChat-Max

## YandexGPT

**Статус:** Отложен
**Причина:** Требует Yandex Cloud IAM token или API key

**Требуемая авторизация:**
1. Создать сервисный аккаунт в Yandex Cloud
2. Получить IAM token или API key
3. Использовать IAM token в заголовке Authorization: Bearer {iam_token}
4. Или использовать API key в заголовке Authorization: Api-Key {api_key}

**Документация:**
- IAM token: https://yandex.cloud/en/docs/iam/concepts/authorization/iam-token
- API key: https://yandex.cloud/en/docs/iam/concepts/authorization/api-key
- YandexGPT API: https://cloud.yandex.ru/docs/yandexgpt/

**Бесплатный тариф для физлиц:**
- 50,000 токенов на год
- Модели: YandexGPT Lite, YandexGPT Pro (частично)
- Цена после лимита: ~40 копеек за 1000 токенов

## Многоязычность (i18n)

**Статус:** Отложено
**Приоритет:** Средний

**Что нужно сделать:**
1. Подключить библиотеку для интернационализации (vue-i18n)
2. Создать файлы переводов для поддерживаемых языков
3. Вынести все текстовые строки из компонентов в файлы переводов
4. Добавить переключатель языка в настройки
5. Сохранять выбранный язык в localStorage

**Поддерживаемые языки:**
- Русский (по умолчанию)
- Английский

**Файлы переводов:**
- `frontend/src/locales/ru.json` - русский
- `frontend/src/locales/en.json` - английский

**Пример структуры переводов:**
```json
{
  "settings": {
    "provider": "Провайдер",
    "model": "Модель",
    "apiKey": "API-ключ"
  }
}
```

**Порядок действий:**
1. Установить vue-i18n
2. Создать структуру локалей
3. Заменить хардкод строки на $t()
4. Добавить переключатель языка в настройки
5. Тестирование
