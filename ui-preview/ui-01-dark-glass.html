Можешь объяснить как работает async/await в Python? И как правильно использовать его с FastAPI?
✦
PulsarAI14:23
async/await — это синтаксис для написания асинхронного кода в Python. В основе лежит event loop из модуля asyncio.

В FastAPI почти все эндпоинты определяются как async def — это позволяет обрабатывать тысячи запросов одновременно без блокировки потока. Хотите увидеть пример сравнения синхронного и асинхронного кода?

Да, покажи пример пожалуйста
✦
PulsarAI14:24
Конечно! Вот сравнение:

Синхронный подход:
def get_data(): time.sleep(1); return data

Асинхронный (FastAPI):
async def get_data(): await asyncio.sleep(1); return data

Ключевое отличие: во время await event loop может обрабатывать другие запросы. Это критично при работе с I/O — базами данных, HTTP-запросами, файлами.
