async/await — это синтаксис для написания асинхронного кода в Python. В основе лежит event loop из модуля asyncio.

В FastAPI почти все эндпоинты определяются как async def — это позволяет обрабатывать тысячи запросов одновременно без блокировки потока.

Конечно! Вот сравнение:

Синхронный: def get_data(): time.sleep(1); return data

Асинхронный: async def get_data(): await asyncio.sleep(1); return data

Ключевое отличие: во время await event loop может обрабатывать другие запросы.
