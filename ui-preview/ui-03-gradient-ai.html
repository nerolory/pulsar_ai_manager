Как работает async/await в Python и как использовать с FastAPI?
✦
PulsarAI14:23
async/await — синтаксис для асинхронного кода. В основе event loop из asyncio.

В FastAPI эндпоинты определяются как async def — это позволяет обрабатывать тысячи запросов без блокировки потока. Показать пример?
U
Вы14:24
Да, покажи пример пожалуйста
✦
PulsarAI14:24
Синхронный:
def get_data(): time.sleep(1); return data

Асинхронный (FastAPI):
async def get_data(): await asyncio.sleep(1); return data

Во время await event loop обрабатывает другие запросы — критично для I/O операций.
