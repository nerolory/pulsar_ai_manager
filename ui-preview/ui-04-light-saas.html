Как работает async/await в Python и как использовать с FastAPI?
✦
PulsarAI14:23
async/await — синтаксис для асинхронного кода. В основе event loop из asyncio.

В FastAPI эндпоинты определяются как async def — это позволяет обрабатывать тысячи запросов без блокировки.

Синхронный: def get(): time.sleep(1); return data

Асинхронный: async def get(): await asyncio.sleep(1); return data
